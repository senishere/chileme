# 吃了么

“吃了么”是一个本地优先的 iPhone PWA，用于快速记录刚吃过的食物、零食和饮水，并查看粗略营养汇总。

## 运行

```bash
npm run serve
```

然后打开：

```text
http://127.0.0.1:4173/
```

在 iPhone Safari 中打开后，可以使用分享菜单里的“添加到主屏幕”。

## 测试

```bash
npm test
```

## 范围

- 数据保存在当前浏览器本地。
- 内置常见主食、蛋白质、饮品、零食、包装食品和中式餐食的粗略营养数据。
- 支持 g 和 ml 份量；液体可用密度把体积粗略换算成重量。
- 汇总热量、蛋白质、碳水、脂肪、钠和饮水。
- 照片只作为记录附件，不参与识别、估重或营养计算。
- 营养数值是粗略估算，不是医疗建议。
