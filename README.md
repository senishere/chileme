# 吃了么

“吃了么”是一个本地优先的 iPhone PWA，用于快速记录刚吃过的食物、零食和饮水，并查看粗略营养汇总。

## 运行

```bash
npm run serve
```

然后打开：

```text
http://127.0.0.1:4173/
```

在 iPhone Safari 中打开后，可以使用分享菜单里的“添加到主屏幕”。

本地 `http://127.0.0.1:4173/` 适合电脑开发预览。iPhone 真机要脱离 PC 使用，需要把这个目录作为静态站点部署到 HTTPS 地址；Safari 只有在安全上下文中才会注册 service worker。

## 离线与部署

应用内置 `sw.js`，会缓存 HTML、JS、CSS、manifest 和图标。部署到 HTTPS 后，首次联网打开一次页面，等首页加载完成，再用 Safari 分享菜单添加到主屏幕；之后即使离线，也可以启动已缓存的应用壳，饮食记录继续保存在手机本地。

可选部署方式：

- GitHub Pages：把仓库推到 GitHub，Pages 来源选择仓库根目录。
- Cloudflare Pages、Netlify 或 Vercel：按静态站点部署，发布目录使用仓库根目录，不需要构建命令。

每次更新应用代码后，需要在联网状态下重新打开一次 HTTPS 页面，让 service worker 拉取新版本缓存。

## 范围

- 数据保存在当前浏览器本地。
- 内置常见细粮、粗粮、动物蛋白、植物蛋白、奶、饮料、坚果、零食和餐食的粗略营养数据。
- 记录时只使用 g/ml；ml 按 1ml = 1g 粗略换算。
- 食物营养统一按每 100g 录入。
- 汇总热量、蛋白质、碳水、脂肪、钠和饮水。
- 支持按分类/最常吃筛选快捷添加，食物页可搜索、管理分类、选择图标并编辑食物。
- 支持导出最近 7 天或 30 天记录明细为 CSV/JSON。
- 支持按个人基础资料生成粗略每日结构目标，并显示严重不足、不足、正常范围、偏高或超量。
- 照片只作为记录附件，不参与识别、估重或营养计算。
- 营养数值是粗略估算，不是医疗建议。
