## 已完成

- iPhone 可用的本地优先 PWA。
- 支持 HTTPS 部署后的 service worker 离线启动；首次联网打开后会缓存应用壳。
- 首页合并版交互：快捷添加左右滚动，时间线上下滚动。
- 支持任意时间记录食物、零食、饮水。
- 支持照片附件；照片只用于回忆，不参与识别、估重或营养计算。
- 记录统一使用 `g` 和 `ml`；`ml` 按 `1ml = 1g` 粗略换算。
- 食物营养统一按每 `100g` 录入，不再使用旧式估算输入或包装规格。
- 营养汇总包含热量、蛋白质、碳水、脂肪和饮水；导出明细仍保留钠字段。
- 首页快捷添加支持“最常吃”和食物分类筛选。
- 食物页支持分类筛选、搜索、常用标记、分类管理、图标选择和编辑现有食物。
- 设置页支持导出最近 7 天或 30 天记录明细为 CSV/JSON。
- 今日页支持按个人资料和目标显示粗略饮食结构状态：严重不足、不足、正常范围、偏高或超量；今日结构不显示钠。
- 内置常见细粮、粗粮、动物蛋白、植物蛋白、奶、水、饮料、坚果、零食、蔬菜、水果和餐食。
- 旧数据升级时会迁移食物分类、每 100g 营养、单位和缺失的内置食物；用户已有同 id 食物不会被覆盖。
- 用户编辑数据保存在当前浏览器/主屏幕 App 的本地存储；删除并重新添加 iOS 主屏幕 App、清站点数据或换域名会导致本地数据不可见，需用设置页 JSON 导出/导入恢复。

## 使用提示

- 电脑和 iPhone 需要在同一个 Wi-Fi。
- 运行 `npm run serve` 后，在 iPhone Safari 打开 `http://192.168.0.104:4173/`。
- 如果 `4173` 被占用，可改用相邻端口运行静态服务，并在手机地址中同步替换端口。
- 如果看到旧页面，刷新或关闭后重新打开。
- 可以用 Safari 分享菜单里的“添加到主屏幕”安装成主屏幕应用。
- 营养数值是粗略估算，不是医疗建议。

## 下一轮计划列表

1. 脱离 PC 使用
   - 已增加 `service worker`，缓存 `index.html`、JS、CSS、manifest 和图标，让 App 首次联网打开后可离线启动。
   - 已在 README 写明 HTTPS 静态部署方案：GitHub Pages、Cloudflare Pages、Netlify 或 Vercel。
   - 未实际发布到公网；部署后在 iPhone Safari 打开 HTTPS 地址，并添加到主屏幕；个人饮食记录继续保存在手机本地。

2. 食物分类与快速查找
   - 已使用可管理的 `categories`、食物 `category` 和 `quickAdd` 字段。
   - 首页快捷添加已支持“最常吃”和分类横向筛选。
   - 食物页已支持分类筛选、搜索、标记常用或取消常用。
   - 分类支持新增、重命名、删除；删除分类会把食物迁移到“其他”。

3. 自定义食物录入
   - 新增/编辑食物共用同一表单。
   - 已统一为每 `100g` 营养录入。
   - 已支持食物分类、图标、图片、热量、蛋白质、碳水、脂肪、钠含量。
   - 食物页已增加编辑现有食物入口。

4. 周/月饮食记录导出
   - 已支持导出最近 7 天和最近 30 天饮食记录。
   - 已支持 CSV 和 JSON。
   - 导出内容包含日期时间、食物、数量、单位、热量、蛋白质、碳水、脂肪、钠、饮水、备注；不包含照片。

5. 每日饮食结构缺口/过量图示
   - 已增加个人基础资料：性别、年龄、身高、体重、活动水平、目标（维持/减脂/增肌）。
   - 已基于这些信息生成粗略每日目标：热量、蛋白质、碳水、脂肪、饮水。
   - 今日页已增加进度条图示，显示每项是否严重不足、不足、正常范围、偏高或超量。
   - 图示不做医疗判断，只做粗略提醒，并标注“估算值”。
