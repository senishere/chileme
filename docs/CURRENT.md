## 已完成

- iPhone 可用的本地优先 PWA。
- 首页合并版交互：快捷添加左右滚动，时间线上下滚动。
- 支持任意时间记录食物、零食、饮水。
- 支持照片附件；照片只用于回忆，不参与识别、估重或营养计算。
- 支持 `g` 和 `ml` 份量。
- 支持 `per100g`、`per100ml`、`perServing`、`perPackage` 营养标注。
- 支持液体密度 `densityGPerMl`，用于把 ml 粗略换算为重量。
- 营养汇总包含热量、蛋白质、碳水、脂肪、钠和饮水。
- 内置常见主食、蛋白质、饮品、零食、包装/高钠食品、轻食和中式餐食。
- 旧数据升级时会补齐钠、单位和缺失的内置食物；用户已有同 id 食物不会被覆盖。

## 下一轮计划列表

1. 脱离 PC 使用
   - 增加 `service worker`，缓存 `index.html`、JS、CSS、manifest 和图标，让 App 首次联网打开后可离线启动。
   - 准备 HTTPS 静态部署方案，例如 GitHub Pages、Cloudflare Pages、Netlify 或 Vercel。
   - 部署后在 iPhone Safari 打开 HTTPS 地址，并添加到主屏幕；个人饮食记录继续保存在手机本地。

2. 食物分类与快速查找
   - 为常吃食物增加分类系统，避免一直左右滑动。
   - 初始分类建议：最常吃、主食、饮品、肉类、蛋类、豆制品、奶类、蔬菜、水果、零食/坚果、包装食品、调味品/高钠、水。
   - 首页快捷添加可按分类横向分组，食物库增加分类筛选和搜索。
   - 支持用户把食物标记为“最常吃”或取消常用。

3. 自定义食物与包装食品录入
   - 现有代码已有新增食物表单，但入口和包装食品流程不够清晰；下一轮需要重新设计成更明显的“自定义食物/包装食品”流程。
   - 包装食品应支持按配料表/营养成分表录入：每 100g、每 100ml、每份、整包。
   - 支持设置默认份量、单位 `g/ml`、每份重量/容量、整包重量/容量、钠含量。
   - 增加编辑已有食物和编辑份量的入口。

4. 周/月饮食记录导出
   - 支持导出最近 7 天和最近 30 天饮食记录。
   - 导出格式优先做 CSV 和 JSON；CSV 便于表格查看，JSON 便于备份和恢复。
   - 导出内容包含日期时间、食物、份量、单位、热量、蛋白质、碳水、脂肪、钠、饮水、备注。

5. 每日饮食结构缺口/过量图示
   - 增加个人基础资料：性别、年龄、身高、体重、活动水平、目标（维持/减脂/增肌）。
   - 基于这些信息生成粗略每日目标范围：热量、蛋白质、碳水、脂肪、钠、饮水，以及蔬菜/水果等结构性目标。
   - 今日页增加直观图示，显示每项是否不足、接近目标或过量。
   - 图示不做医疗判断，只做粗略提醒；需要明确标注“估算值”。
